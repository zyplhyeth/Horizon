# 评分目的

为在湖南三四线城市经营餐饮与外卖的读者筛选**近期、可信、可进一步尽调的餐饮品牌情报**。分析新闻价值，不评定真实投资收益。品牌必须有可识别名称及发生时间；“公司实力”必须有具体证据。

# 0–10 分评分规则

- 9–10：权威公告/财报或至少两家相互独立的可信报道支持重大新品牌发布、明确的投资/直营扩张、加盟开放，且有可核实的数据和母公司背景。
- 7–8：权威专业媒体报道近期新品牌/集团新业务，包含可识别企业主体与实质经营数据；至少明确一个可进一步验证的实力信号。
- 5–6：有新闻价值的可信线索但只有单一来源、缺少直营/财务/门店证据；可列作“观察中”，不得写为“实力已核实”。
- 3–4：缺少基本数据、较旧、重复、只有招商意图或品牌自述，无独立支撑。
- 0–2：虚构或不具名品牌、保证收益、夸大加盟回本、营销软文、传闻、无法核实主体。

# 严格规则

1. 优先近24个月推出的品牌或新开放加盟模式；旧品牌扩张也可以入选但须说明并非新品牌。
2. 仅引用报道中存在的信息；不要凭经验编造融资金额、店铺数、加盟费、毛利率、回本期或当地加盟资格。
3. 发行人/招商公司声明、专业媒体转述、政府公示三者证据等级不同；任何财务预测都标明来源、统计口径和日期。
4. 无法确认备案、工商、直营店、资金、盈利时，明确写“待核实”。有备案不意味着盈利可靠。
5. 同一品牌多篇报道以更新、更可靠、数据更充分的报道优先。避免只靠标题点赞、重复转载或搜索命中数量加分。
6. 判断湖南三四线城市适配时只能提出待验证的问题，不得擅自认定适合开店。

使用3–5个具体主题标签，例如“餐饮新品牌”“特许经营”“直营门店”“集团孵化”“供应链”。
